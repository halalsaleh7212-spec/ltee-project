# Code of conduct

Everyone taking part in this project, including issues, pull requests, and
discussions, follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/).

Report unacceptable behaviour to Hala Alsaleh at
[hala.Alsaleh@mbzuai.ac.ae](mailto:hala.Alsaleh@mbzuai.ac.ae). Reports are
handled confidentially.
