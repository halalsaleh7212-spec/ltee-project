# Project structure

| Folder | Contents | How it is maintained |
|--------|----------|----------------------|
| `data/raw/` | FASTQ reads and compressed REL606 reference downloaded by `scripts/download_data.py` | Read-only data; downloaded and verified, not committed |
| `data/processed/` | Decompressed reference and reference indexes | Regenerated by the workflow; not committed |
| `metadata/` | Sample sheet, source URLs, provider checksums, and SHA-256 checksums | Small text files committed to Git |
| `scripts/` | Download, FASTQ summary, shell-pipeline, and variant-comparison code | Committed |
| `config/` | `config.yaml`, shared analysis settings for Snakemake and Nextflow | Committed |
| `workflow/` | Snakemake `Snakefile` and `nextflow/` workflow and configuration | Committed |
| `notebooks/` | Exploratory notebooks | Source committed; avoid large generated outputs |
| `reports/` | Quarto report source and bibliography; rendered HTML and PDF | Source committed; rendered reports regenerated and ignored by Git |
| `results/` | QC reports, variant calls, statistics, sensitivity outputs, and logs; shell comparison results in `shell-script/`, Nextflow outputs in `nextflow/` | Regenerated; not committed |
| `docs/` | Structure guide, decisions, validation notes, container history, software versions, and workflow diagram | Committed documentation |
| `envs/` | Location for Conda environment exports when needed | Exports are generated from the Pixi environment; `pixi.lock` remains the exact software record |
| `containers/` | Docker and Apptainer recipes; local image archives | Recipes committed; saved images ignored by Git |
| `.github/workflows/` | Automated reproduction checks | Committed |
| `.pixi/`, `.snakemake/`, `.nextflow/`, `work/` | Installed environments and workflow state or task caches | Local generated state; ignored by Git |

At the repository root, `pixi.toml` defines dependencies and tasks, and
`pixi.lock` records exact package versions. `_quarto.yml` controls report
execution. `README.md` provides the entry point, `CITATION.cff` defines the
citation, and `CONTRIBUTING.md` and `CODE_OF_CONDUCT.md` explain participation.
`LICENSE` contains the software license; the README describes the licenses
for the other materials.
